# زاگرس — جهان کولاک

فروشگاه آنلاین لوازم خانگی و برودتی + خدمات تعمیرات، پشتیبانی و باشگاه مشتریان.
کاملاً خودمیزبان، بهینه برای سرور کم‌منبع، مقاوم به قطعی اینترنت بین‌الملل.

## استک
Rust · Axum · sqlx (PostgreSQL) · askama + HTMX (SSR) · فونت خودمیزبان وزیرمتن · جستجوی فارسی pg_trgm · ربات تلگرام (reqwest)

> یادداشت: جستجو فعلاً با **pg_trgm** است (Meilisearch به‌خاطر محدودیت دیسک مؤجل شده) و ربات با آداپتور **reqwest** پیاده شده (به‌جای teloxide). جزئیات در `PLAN.md` و `DEPLOY.md`.

## اجرا
```bash
./scripts/dev.sh run        # اجرای سرور توسعه (پورت ۸۰۸۰)
./scripts/dev.sh build      # کامپایل
./scripts/dev.sh release    # کامپایل نهایی (بهینه)
./scripts/dev.sh disk       # وضعیت فضای دیسک
./scripts/dev.sh clean-disk # آزادسازی فضا
```

## استقرار تولید
راهنمای کامل در `DEPLOY.md`. پیکربندی آماده در `deploy/`:
- `deploy/zagros.service` — یونیت systemd (سخت‌سازی‌شده، سقف حافظه)
- `deploy/nginx.conf` — reverse proxy + TLS + WebSocket چت + محدودیت نرخ

## دیتابیس
PostgreSQL روی `127.0.0.1:5432`، دیتابیس و یوزر `zagros`.
migrationها در `migrations/` و خودکار هنگام اجرا اعمال می‌شوند.

## ساختار
- `crates/web` — اپ Axum (SSR، روت‌ها، asset)
- `crates/db` — اتصال و migration
- `crates/domain` — منطق دامنه (پول، خطاها)
- `crates/payments` — انتزاع درگاه (زرین‌پال/زیبال)
- `crates/sms` — انتزاع پیامک (کاوه‌نگار/SMS.ir/کنسول)
- `crates/bot` — ربات تلگرام (آداپتور reqwest، long-polling)
- `templates/` (داخل web) — قالب‌های askama، فارسی RTL
- `assets/` — CSS، فونت، تصاویر (همه لوکال)

وضعیت کامل و نقشه‌ی فازها در `PLAN.md`.

### افزوده‌های پنل ادمین
- [x] **مدیریت محصول (CRUD کامل)**: فهرست، ساخت/ویرایش، حذف، فعال/غیرفعال و منتخب‌کردن؛ مدیریت تنوع‌ها (قیمت/موجودی/SKU) و تصاویر (تصویر اصلی)؛ اعتبارسنجی نامک و یکتایی؛ ورودی قیمت به تومان؛ باطل‌سازی خودکار کش صفحه‌ی اصلی پس از هر تغییر.
- [x] **مدیریت دسته‌بندی و برند (CRUD)**: ساخت/ویرایش/حذف دسته (با والد درختی، جلوگیری از حلقه)، فعال/غیرفعال؛ ساخت/ویرایش/حذف برند؛ شمار محصولات هر دسته/برند؛ حذف امن (محصولات حذف نمی‌شوند، فقط بی‌دسته/بی‌برند می‌شوند). کمک‌توابع فرم در `routes/admin_util.rs` مشترک شده‌اند.
- [x] **پنل کامل مدیریت سایت** — همه‌ی بخش‌ها از ادمین قابل‌مدیریت‌اند:
  - **سفارش‌ها**: فهرست با فیلتر وضعیت + موبایل مشتری، جزئیات کامل (اقلام، آدرس، پرداخت، تخفیف)، تغییر وضعیت.
  - **کاربران**: فهرست/جستجو، جزئیات (سفارش‌ها/امتیاز/تعمیرات)، فعال/مسدود (مدیر محافظت‌شده)، تغییر نقش، تنظیم دستی امتیاز.
  - **تعمیرات و تیکت‌ها**: فیلتر وضعیت (CRUD از قبل کامل بود).
  - **چت زنده**: فهرست فعال/بسته/همه با شمار پیام، بستن از ادمین.
  - **کد تخفیف**: CRUD کامل (درصدی/ثابت با سقف، حداقل سفارش، انقضا، سقف استفاده).
  - **تنظیمات سایت (زنده، بدون ری‌استارت)**: نام سایت، تماس، هزینه‌ی ارسال، استان پرداخت در محل، نرخ امتیاز، تاگل پرداخت آنلاین — از جدول `settings` با کش زنده (`SettingsCache`). رازها (توکن ربات، مرچنت، secret) فقط از ENV و فقط‌خواندنی نمایش داده می‌شوند.
  - **داشبورد**: کارت‌های شمارش کاتالوگ/عملیات، همه لینک‌دار به بخش مربوطه.
  - ناوبری ادمین در یک partial مشترک (`admin/_nav.html`) با تب فعال خودکار.
