## ۱) خلاصه‌ی محصول

فروشگاه آنلاین لوازم خانگی با تمرکز برودتی (یخچال، فریزر، آبسردکن) + جارو/آبمیوه‌گیری و…، به‌علاوه‌ی سه سیستم جدی:
- **فروشگاه کامل:** کاتالوگ، فیلتر پیشرفته، سبد خرید، پرداخت چنددرگاهه، فاکتور.
- **سیستم تعمیرات:** ثبت دستگاه خراب → یا اعزام متخصص به محل، یا آوردن به انبار؛ پیگیری وضعیت.
- **پشتیبانی:** تیکت + چت زنده‌ی Real-time (WebSocket).
- **باشگاه مشتریان:** امتیاز، کد تخفیف، کلاب، امتیازگیری از طریق **ربات تلگرام**.

**اصول قطعی:**
- ۱۰۰٪ خودمیزبان، بدون هیچ CDN/سرویس خارجی → مقاوم به قطع اینترنت بین‌الملل ایران.
- اجرا روی همین سرور (۱ هسته / ۳.۸ گیگ رم) — معماری فوق‌سبک.
- SEO جدی (رندر سمت سرور، هدف رتبه‌ی اول گوگل).
- RTL فارسی کامل، واحد پول **تومان** در UI / **ریال** در مرز درگاه.

## ۳) معماری کلی

```
                 ┌────────────────────────────────────────────┐
   Browser ──────► nginx/Caddy (TLS, gzip/br, static, rate-limit)
   (HTMX)         └───────────────┬────────────────────────────┘
                                  │
                    ┌─────────────▼─────────────┐     ┌──────────────┐
                    │     اپ Rust (Axum)         │────►│ PostgreSQL 16│
                    │  - SSR (askama) + HTMX     │     │ (داده + صف   │
                    │  - REST/Hypermedia routes  │     │  apalis)     │
                    │  - WebSocket (چت زنده)     │     └──────────────┘
                    │  - moka cache (درون‌حافظه)  │     ┌──────────────┐
                    │  - apalis workers          │────►│ Meilisearch  │
                    │  - PaymentGateway trait    │     │ (جستجوی فا)  │
                    │  - SmsSender trait         │     └──────────────┘
                    └──────┬──────────────┬──────┘
                           │              │
                   ┌───────▼──────┐  ┌────▼─────────┐
                   │ teloxide bot │  │ درگاه‌ها/پیامک │
                   │ (امتیاز/کلاب)│  │ (زرین‌پال/زیبال│
                   └──────────────┘  │  کاوه‌نگار...) │
                                     └──────────────┘
```

**یک باینری، چند نقش:** اپ وب، ورکرهای صف، و ربات تلگرام در یک پروسه (task جدا) بالا میان — ساده‌ترین و کم‌مصرف‌ترین برای این سرور. قابلیت جداسازی بعداً حفظ می‌شه.

## ۴) ساختار پروژه (Cargo workspace)

```
zagros/
├─ Cargo.toml                # workspace
├─ crates/
│  ├─ web/         # اپ اصلی Axum: routes، SSR، htmx، websocket
│  ├─ domain/      # منطق کسب‌وکار، مدل‌ها، خطاها (مستقل از وب/دیتابیس)
│  ├─ db/          # sqlx، migrationها، repositoryها
│  ├─ payments/    # trait PaymentGateway + آداپتور زرین‌پال/زیبال
│  ├─ sms/         # trait SmsSender + آداپتور کاوه‌نگار/SMS.ir
│  ├─ search/      # trait + آداپتور Meilisearch (fallback به pg_trgm)
│  ├─ jobs/        # apalis: ایمیل، ایندکس جستجو، عکس، یادآوری تعمیر
│  └─ bot/         # teloxide: ربات تلگرام، اتصال امتیاز
├─ templates/      # askama (RTL فارسی)
├─ assets/         # CSS/JS/تصاویر — همه لوکال، بدون CDN
├─ migrations/     # SQL
└─ config/         # config.toml + .env
```

## ۵) دیتابیس — جداول اصلی (طرح کلی)

- **users** (موبایل یکتا، ایمیل اختیاری، نقش، امتیاز، تلگرام_id)
- **otp_codes** (کد، انقضا، تلاش‌ها) — کد در اپ تولید/محدود می‌شه
- **categories** (درختی، والد)
- **products** (نام، نام_نرمال‌شده‌ی فارسی، slug، برند، توضیح، فعال) + **name_norm** ژنریت‌شده با `fa_normalize` + ایندکس `pg_trgm`
- **product_variants** (رنگ/سایز/مدل، قیمت ریالی، موجودی، sku)
- **product_images** (مسیر WebP/AVIF، ترتیب)
- **product_attributes** + **attribute_values** (برای فیلتر پویا: حجم یخچال، نوع، رنگ…)
- **carts / cart_items**
- **orders / order_items** (وضعیت، آدرس، روش پرداخت، مبلغ ریالی)
- **payments** (`order_id, provider, gateway_token, amount, state, ref_id`) — هسته‌ی انتزاع درگاه
- **repair_requests** (کاربر، نوع دستگاه، مشکل، روش: اعزام/انبار، وضعیت، فنی مسئول، آدرس)
- **repair_status_log** (تاریخچه‌ی وضعیت)
- **tickets / ticket_messages** (پشتیبانی غیرلحظه‌ای)
- **chat_sessions / chat_messages** (چت زنده)
- **coupons** (کد، درصد/مبلغ، سقف، انقضا، شرط)
- **loyalty_transactions** (کسب/خرج امتیاز، منبع: خرید/تلگرام)
- **addresses** (کاربر، استان، شهر — پرداخت در محل فقط **زنجان**)
- **settings** (کلید-مقدار: درگاه فعال، پیامک فعال، …)

نرمال‌سازی فارسی (`ی/ک` عربی↔فارسی، ZWNJ، ارقام) در سطح دیتابیس برای صحت جستجو و یکتایی، مستقل از Meilisearch.

## ۶) فازبندی تحویل (هر فاز تست‌شده و قابل‌اجرا)

**فاز ۰ — زیرساخت (پایه)**
- نصب Rust/musl، راه‌اندازی workspace، اتصال Postgres، migration اولیه، اسکلت Axum + askama + HTMX، layout فارسی RTL، سیستم config، فعال‌سازی swap، healthcheck.

**فاز ۱ — هسته‌ی فروشگاه (اولین خروجی قابل‌دیدن) ⭐**
- کاتالوگ، دسته‌بندی درختی، صفحه‌ی محصول، فیلتر و جستجو (اول pg_trgm)، سبد خرید، صفحه‌ی اصلی. + پنل ادمین پایه برای محصول/دسته. + SEO پایه (slug، meta، sitemap، schema.org).

**فاز ۲ — حساب کاربری و پرداخت**
- ثبت‌نام/ورود با موبایل (OTP) + ایمیل، نشست، آدرس، تسویه، **درگاه پرداخت** (زرین‌پال+زیبال پشت trait، فعال‌سازی از تنظیمات)، فاکتور، تاریخچه‌ی سفارش.

**فاز ۳ — تعمیرات**
- ثبت درخواست تعمیر (اعزام/انبار)، پیگیری وضعیت، پنل ادمین تعمیرات، اعلان (پیامک/ایمیل از طریق صف).

**فاز ۴ — پشتیبانی**
- سیستم تیکت + **چت زنده‌ی WebSocket** + پنل اپراتور.

**فاز ۵ — باشگاه مشتریان + ربات تلگرام**
- امتیاز، کد تخفیف، کلاب، و **ربات teloxide کامل**: اتصال حساب، امتیازگیری، اطلاع‌رسانی.

**فاز ۶ — تقویت: Meilisearch + بهینه‌سازی نهایی**
- جایگزینی/تکمیل جستجو با Meilisearch (`locales:["pes"]`)، کش moka، فشرده‌سازی asset، WebP/AVIF خودکار، ممیزی SEO و سرعت، استقرار نهایی با systemd.

> از **اسکیل UI/UX** (`ui-ux-pro-max`) برای طراحی سیستم بصری (پالت، تایپوگرافی فارسی، الگوهای فروشگاهی، چک‌لیست تحویل) در فاز ۱ استفاده می‌کنم.

## ۷) ریسک‌ها و مدیریتشان (صادقانه)

1. **فضای دیسک (۴.۲ گیگ آزاد):** پوشه‌ی `target/` کامپایل Rust بزرگ می‌شه. → بیلد بهینه، پاک‌سازی دوره‌ای، نبود نصب‌های اضافی. اگر تنگ شد، اطلاع می‌دم.
2. **۱ هسته برای کامپایل:** بیلد اولیه کند خواهد بود (نه اجرای سایت). → swap فعال می‌کنم؛ اجرا سریع و کم‌مصرف می‌مونه.
3. **سندباکس زرین‌پال تعطیل شده:** تست با حداقل ۱۰۰۰ ریال یا shim؛ معماری idempotent (کد ۱۰۱/۲۰۱).
4. **همزیستی Postgres + Meili + اپ روی ۳.۸ گیگ:** Meili را با حافظه‌ی محدود تنظیم و پشت trait؛ در صورت فشار، fallback به Postgres.

## ۸) چیزی که از تو لازم می‌شه (در طول مسیر، نه الان)

- اطلاعات درگاه پرداخت (merchant زرین‌پال/زیبال) — موقع فاز ۲.
- کلید پنل پیامک (کاوه‌نگار/SMS.ir) + شناسه‌ی قالب OTP — موقع فاز ۲.
- توکن ربات تلگرام (از @BotFather) — موقع فاز ۵.
- دامنه‌ی نهایی برای TLS و SEO — موقع استقرار.

تا اون موقع همه‌چیز با حالت تست/شبیه‌ساز پیش می‌ره و سایت بدون این‌ها هم بالا میاد.
